# Browser logo sources

- `chromecraft.svg`: faithful vector version of the rounded blue `C` mark used by the Chromecraft browser shell.
- `chrome.svg`: WHATWG browser logo resources, `https://resources.whatwg.org/browser-logos/chrome.svg`.
- `edge.svg`: WHATWG browser logo resources, `https://resources.whatwg.org/browser-logos/edge.svg`.
- `firefox.svg`: Mozilla Firefox official branding asset, `https://github.com/mozilla-firefox/firefox/blob/main/browser/branding/official/content/about-logo.svg`.

Third-party product names and logos remain trademarks of their respective owners and are used only for truthful product comparison.
