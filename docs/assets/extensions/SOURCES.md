# Extension logo sources

- uBlock Origin: bundled project asset at `resources/extensions/ublock-origin/img/ublock.svg`.
- Bitwarden and 1Password: Simple Icons CDN, retrieved 2026-10-22.
- Chrome Web Store: Wikimedia Commons `Google_Chrome_Web_Store_icon_2022.svg`, retrieved 2026-10-22.
- Bing: Microsoft-hosted `OMR.MicrosoftProducts.Bing.svg`, retrieved 2026-10-22.
- Microsoft Rewards: official `rewards-icon-96.png` from `rewards.bing.com`, retrieved 2026-10-22.
- Trustpilot: official `single-star-transparent.svg` brand asset from `cdn.trustpilot.net`, retrieved 2026-10-22.

The displayed PNG files are local raster renderings of these sources so the logos remain visible on static preview servers that do not send SVG MIME types correctly.

The marks remain trademarks of their respective owners and are used here only to identify compatible browser extensions and the Chrome Web Store.
